このアプリについて

M_SEQ は、指1本で演奏して、そのまま録音できる 8bit サウンドのシーケンサーです。 画面下の XY パッドを指でなぞると音が鳴り、 そのまま繰り返し（ループ）として記録されます。

音は昔の家庭用ゲーム機と同じ考え方で、その場で計算して作っています。 録音した音のファイルは使っていません。

今後の予定

M_SEQ は、音源を足していけるシーケンサーとして作っています。 演奏のしかた（XY パッド・録音・ループ）は共通で、 鳴らす音だけを差し替えていく形です。

今回公開した 8bit SEQ は、その最初の音源です。 今後、別の音源をアプリ内の追加購入として順次加えていく予定です。

基本の使い方

1. 音を出す

画面下の大きな四角（XY パッド）を指でなぞってください。

  • 左右 … 音の高さ（左が低く、右が高い。左端から右端で2オクターブ）
  • 上下 … 鳴らし方（GATE＝連打 / ARP＝疑似和音 / VIB＝揺れ）

2. 録音する

  • ● を押してから、パッドをなぞる
  • 指を離すと、そこまでが1回ぶんの録音になります
  • もう一度なぞると、上から重ねて録音できます（オーバーダブ）

3. ボタン

▶ / ■再生 / 停止。押すと必ず先頭から始まります
●録音の入り切り
↺ひとつ前に戻す（20回まで）
TC選んでいる1本のトラックの録音を消す
AC4本すべての録音を消す
電球点いている間、次にさわる場所が光ります（パッド → ● → パッド → トラック）。最後までさわると消えます。押すと点け直せます
♪=速さ（BPM）。上下になぞって変えます

4. トラック

TRK1・TRK2・TRK3・DRUM の4本があります。 名前の部分を押すと、そのトラックに切り替わります。

各項目はタップで次へ、 上下になぞっても変わります。 音量つまみは、上へなぞると大きく、下へなぞると小さくなります。 つまみをダブルタップすると 80 に戻ります。

よくある質問

作った曲は保存できますか？

いまのバージョンでは保存できません。 アプリを閉じると消えます。 その場で作って、その場で演奏するための道具として作っています。

指を置いてから音が出るまで、少し遅れます

これは仕様です。 すべての音が拍にきっちり合うように、 いちばん近い16分音符の区切りまで待ってから鳴らしています。 待ち時間は最大で16分音符1つぶん（BPM 120 のとき約0.13秒）です。

速さ（BPM）を上げると、待ち時間も短くなります。

音が出ません

  • 本体の消音スイッチが入っていないか確認してください
  • 音量を上げてください
  • トラックの M（消音）が入っていないか確認してください
  • どこかのトラックで S（独奏）が入っていると、他は鳴りません

DRUM のパッドが他と違います

DRUM だけは指の位置が「どう叩くか」を決めます。 右へ行くほど細かく、上へ行くほど楽器が増えます。 左下はバスドラムだけ、右上はにぎやかな演奏になります。

STYLE が BREAK のときだけは、しくみが違います。 有名なブレイクビーツ「アーメンブレイク」を切って並べ替えて鳴らします。 右へ行くほど細かく切り、上へ行くほどたくさん並べ替えます。 左端といちばん下はアーメンブレイクそのまま、右上は激しいブレイクコアになります。

About this app (English)

M_SEQ is an 8-bit style performance sequencer. Drag one finger across the XY pad to play, and your performance is recorded as a loop. All sound is synthesized in real time — no audio files are used.

Roadmap

M_SEQ is built as a sequencer that grows by adding sound engines. The way you play — XY pad, recording, looping — stays the same; only the sound changes.

8bit SEQ is the first engine. Additional engines (mallet, acid, and others under consideration) are planned as in-app purchases through the App Store. No release date yet.

8bit SEQ will always remain free.
Features that work today will never be moved behind a purchase.

Requirements

  • iPhone, iOS 17 or later
  • Portrait orientation only
  • No network connection required

Basics

  • XY pad — horizontal: pitch (two octaves), vertical: articulation (GATE / ARP / VIB)
  • ● — arm recording, then drag the pad. Drag again to overdub.
  • ▶ / ■ — play / stop. Playback always starts from the top of the loop.
  • ↺ — undo (up to 20 steps)
  • TC — clear the selected track
  • AC — clear all four tracks
  • Light bulb — while it is on, the next thing to touch lights up (pad, record, pad again, track). It switches off once you have done them all; tap it to turn the guide back on.

FAQ

Can I save my songs?
Not in this version. Everything is cleared when the app closes.

There is a short delay before I hear a note.
This is intentional. Every note starts exactly on a 1/16 note boundary so that what you hear matches what is recorded. The wait is at most one 1/16 note (about 0.13 s at 120 BPM).

No sound.
Check the silent switch, the volume, the per-track M (mute), and whether any track has S (solo) enabled.
